# Weather App

## About the Project

Weather App is a website that allows users to view weather information through a simple and user-friendly interface. This project was developed as part of my web development coursework to practice building interactive websites.

## Features

- Display weather information in an easy-to-understand format.
- Provide a simple and user-friendly interface.
- Present weather data clearly for users.

## Technologies Used

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## What I Learned

Through this project, I practiced creating web pages, styling user interfaces with CSS, and using JavaScript to add functionality. This project helped me strengthen my web development and problem-solving skills.
